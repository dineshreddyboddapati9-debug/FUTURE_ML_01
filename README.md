# Sales Forecasting Model (Task 1)

## Objective

The objective of this project is to build a Machine Learning model that predicts future sales based on historical sales data. This helps businesses make better decisions regarding inventory, production, and planning.

## Problem Statement

Businesses need to forecast future sales to optimize operations and improve profitability. This project uses historical sales data to train a model and predict future sales values.

## Tools and Technologies Used

* Python
* Pandas (Data handling)
* NumPy (Numerical operations)
* Matplotlib (Data visualization)
* Scikit-learn (Machine Learning - Linear Regression)

## Project Files

* task1.py → Main Python code for sales forecasting
* output.txt → Predicted future sales values
* output.png → Visualization graph of sales forecast
* README.md → Project documentation

## How it Works

1. Load historical sales data
2. Prepare data for training
3. Train Linear Regression model
4. Predict future sales
5. Display results and graph

The Machine Learning model successfully predicts future sales based on historical data. This helps businesses plan resources and make informed decisions.
